# Data sources & gaps register

Updated: 2026-10-12 · One place for data the engine needs but does not have yet (or has but does not parse). Each module build checks this list; an entry closes with the decision that covers it. Free sources only for now (S2). Evidence grades per D14.

## Status key
- **gap** — not collected.
- **stored, not parsed** — kept whole in corpus.db and searchable (Tier 2); no extractor yet.
- **partial** — some forms covered; the rest named in Notes.
- **covered** — closed by the decision named.
