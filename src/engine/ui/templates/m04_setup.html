Dickinson signs with core investing = capex + acquisitions − business and asset sale proceeds; a stage holds when 2 of the last 3 fiscal years agree. Review when no stage holds, the held stage is shake-out, the stage conflicts with the 3-year revenue CAGR (introduction/growth below 0%; mature/decline above 20%†), or fewer than 3 fiscal years exist (D-M04-7). A muted line shows where total investing would read differently. Stage routes red flags only (young set for introduction and growth, plus the SG&A rule for growth; mature set for mature and decline; all-stage flags only for shake-out, D-M04-46); R12, inventory-vs-sales and the survival gate run at every stage. The owner's stage keeps routing until you change it; a later 10-K whose computed stage differs, or is ambiguous, opens a new item (D-M04-12).
