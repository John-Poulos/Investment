Checking a guidance row — how to decide, with worked examples (D-M02-24)

Ask three questions

  1. Whose number is it? The company's own total — not a customer's, the industry's, a peer's, or one segment or product line.
  2. Is it about the future? A forecast for a coming period — not a result already reported, and not earlier guidance only retold as history.
  3. Did the parser copy it faithfully? Same metric, period, number, unit and wording ("approximately", "more than", "up to", "including …").

Three yes answers → No error / Correct — no change needed. Spoken wording is not an error: "approximately", "roughly", "about" are normal on calls; the row is stored and shown as approximate, and a company's later filing can upgrade the call's grade B to A. When unsure, leave the item open: a missing value is safer than a wrong one.
